NOOR BABAR SABRI — PORTFOLIO (HTML, CSS, MINIMAL JAVASCRIPT)

Files
- index.html: page content and project cards
- style.css: responsive layout, seven theme palettes, hover/focus states
- script.js: small theme-picker interaction, carousel controls, and contact-form return message
- assets/: seven local hero images
- project image files: local thumbnails used by the project cards

Run locally
1. Extract the complete folder.
2. Keep index.html, style.css, script.js, all project images and the assets folder together.
3. Open index.html in a browser.

Before publishing

Implementation notes
- Project cards are written directly in HTML to keep JavaScript smaller.
- Theme colors and hero artwork are controlled by a small, dependency-free script.
- No external image URLs or JavaScript frameworks are required.
